# EME brand story

## Positioning

- **What we are:** a **Collective Intelligence Platform** (home page H1). Use "infrastructure" only as a supporting word for government and enterprise copy. Tagline: "Empowering Collective Intelligence".
- **Eyebrow / vision line:** "Customizable AI for Everyone".
- **Sub line:** "One open platform. Every AI need. Humans fully in control."
- **Lead:** "EME is an all inclusive AI package delivered through a single, open platform, fully customizable using AI skills."
- **Sign off:** "Own your intelligence. Own your content. Own your future."
- **Organization:** EME World Inc., a Fundación (501(c)(3) foundation). President: Christopher Burkey, cburkey@eme.world,
  +1 513 898-2063. Portal eme.world. Code: github.com/entermedia-community/eme-server. Contact group: the EME World OSPO Team.

## The one idea

AI should serve people and communities, not corporations. EME gives organizations one open, sovereign place for every AI need,
and **humans stay in control**. The assistant never acts on its own for key actions; it relies on human guidance.

## Core ideas (use these exact names)

| Name | Meaning |
|---|---|
| **EME (Electronic Me)** | A person's AI assistant, trained as a personal **digital twin** (their style, schedule, knowledge). The entity is called an **EME Profile**. Do not call it a "persona". |
| **People Driven** | Users add reference files, team guidelines and preferences. Two example modes: *Clear and Precise*, *Friendly and Helpful*. |
| **Omnichannel Communication** | My EME connects app users with teammates who use email. |
| **AI Harness** | The central control system and safety framework. Standardizes how AI tools run tasks, protect security and interact across the organization. |
| **EME Server** | A custom server a team builds on a 100% open source stack, reached through simple chat screens with forms, data tables and graphics. |
| **Chat as the front door** | Everything starts in a conversation. |
| **Open API** | Complete REST API, OpenAI syntax compatible, available to EME servers with no extra charge for usage. |
| **Deployment model** | Predictable flat rate, full data privacy, no corporate connections, no data harvesting, no vendor lock in. Includes hosting, open AI models, dedicated GPU and cloud storage. **Unlimited tokens** on **dedicated hardware**, with no usage charges. |

The 30 harness capabilities (home page cards, each with an icon and a descriptive sentence), in order: Memory, Agents, Chat, Automation, Scheduler, Job Manager, Informatics, Database, Media Management, Storage, Image Creation,
Translation, Transcribing & Voice to Text, Video Editing, Orchestration, MCP Server and Client, Semantic Vector Search, Embeddings (talk to your own documents), Named Entity Recognition (collects named nouns across documents), Markdown Creation (with pagination from images or documents), Automated Tagging (any media file), Facial Recognition, Docker, Git and Linux friendly (deploy direct to servers from Git), Java Based (object oriented, well understood by AI, secure dependencies), Server Sync (bidirectional data sync across data centers), Desktop File Manager (bulk upload and sync files to Linux, Mac and Windows), Smart Organizer (visual database design tool), Workflow Editor (visual workflow planner), Smart Creator (component based WYSIWYG outline editor), Open API.

The AI Harness **diagram** is different: it shows only the industry standard harness components (Interact: Chat, Automation. Reason: Agents, Orchestration. Context: Memory, Knowledge. Connect: Tools and MCP, Open API. Governance and Security across all, on Your EME Server, with Humans in control on top). Every other capability lives only in the cards.

How knowledge is structured (home page section "One language for organizational knowledge", eyebrow "Our terminology"): every EME Server
organizes what it knows as standard **entities**. Use these exact terms: **Person** (free for life login), **EME Profile** (the EME digital twin),
**Team**, **Project**, **Server**, **Channel**, **Document**, **Asset**, **File**, **Category**, **Collection**, **Skill**, **Agent**.
Example sentence: a Person joins a Project on a Server, and shares Documents and Assets in a Channel. Their EME Profile helps along the way.
The older People, Projects, Servers diagram (`overview/emetree.svg`) is no longer on the home page.

## Proof points (real examples, do not invent others)

- **Who we work with:** the United Nations. Clients include Yale and the Canadian Broadcasting Corporation (CBC). Servers are hosted worldwide.
- **Community:** monthly EME Community meetings give feedback to the Open Source Program Office.

- **UN News EME:** editorial workflow from ingest, transcription and indexing, draft synthesis, multilingual and alt text, editorial review, push to Drupal CMS, publication.
- **Cacao Source:** mobile team chat with Employee Training, Company Dashboard and Goal Tracking.
- **Cumbre de Cocreación:** Business Coach, Capacitación y Certificación (LevelUp Guatemala courses), Directorio de Negocios.
- **Example server apps:** Content Creation, Employee Training, Community Bank, Business Coaching, Workforce Scheduling, Regional Ride-Share.
- **Scenario A:** Christopher and Tammy plan a weekend event; EME Christopher checks calendars and offers tickets and a carpool inside the chat. (The long Scenario A section was removed from the home page. It survives in the phone mockup and in documents.)

## Audience

Public sector and NGO leaders, organizations and governments, community organizers, local IT teams and developers.
Developers get the tutorial page (`developers.html`): setup from GitHub, OpenCode to customize the server.

6. **Complete AI Harness:** the standard components diagram, then the 30 capability cards, then flat rate and sovereignty.
7. **Our terminology, "One language for organizational knowledge":** the circular entity diagram, one closing sentence. No glossary cards.
8. **Values.**
9. **Next steps:** contact the OSPO Team, Login.

## What the user prioritized (shapes every new piece)

- **Most compelling parts only, not too many words.** Lead with the mission, the trust proof (UN, Yale, CBC), free for everyone, unlimited tokens on dedicated hardware, and the digital brain and AI economy. Cut paragraphs to one line.
- **Two levels of detail.** Pictures show the essentials (standard harness components, the entity ring). Cards carry everything else, with descriptive text.
- **Practical features matter:** Docker, Git and Linux friendly with deploy direct from Git, Server Sync, Desktop File Manager, MCP server and client, Scheduler, Job Manager, vector search, embeddings, entity recognition, automated tagging, facial recognition, Markdown creation, image creation, and the visual tools (Smart Organizer, Workflow Editor, Smart Creator).
- **Terminology is part of the brand:** the entities are Person, EME Profile, Team, Project, Server, Channel, Document, Asset, File, Category, Collection, Skill, Agent.

## Never claim

- That the AI acts autonomously or replaces people.
- Usage based pricing, vendor lock in, or data sharing with corporations.
- Customers, numbers or integrations that are not in the source documents.
